# Card_Space

鸿蒙 NEXT 元服务卡片「自动组装桌面」演示集合 —— 五个纯静态单文件网页，无需构建，直接打开即可预览。

## 演示一览

| # | 演示 | 路径 | 亮点 |
|---|------|------|------|
| 1 | 多场景卡片桌面 | `harmony-cards/index.html` | 时空意图路由，5 场景 10+ 卡片 |
| 2 | 学生·学习空间生成器 | `student-space/index.html` | 兴趣选择 → 自动拼装，12 项可选 |
| 3 | 旅游·卡片空间（7步流程） | `travel-main/index.html` | 行程时间线，5 阶段，完整 7 步体验 |
| 4 | 旅游·卡片空间（6步直接生成） | `travel-fork/index.html` | 直接生成 + 对话微调，支持小艺语音调行程 |
| 5 | 健身·卡片空间 | `fitness-card/index.html` | 运动数据、课程安排、成就进度多卡组合 |

根目录 `index.html` 为导航首页，链接到以上五个演示。

## 各演示简介

### 📱 多场景卡片桌面（harmony-cards）

按「时空 + 信号意图路由」自动拼装不同场景的卡片桌面：

- 场景：居家晨间 / 通勤中 / 到店健身 / 晚间复盘 / 睡前
- 卡片：健身、追更、基金、学习、快递、用药、天气、音乐、日历、阅读、睡眠等 10+ 张
- 特性：鸿蒙 NEXT 规范（4×7 网格、独立沙箱、整卡热区、编辑收口详情页）、实况窗胶囊、深色模式

### 🎓 学生·学习空间生成器（student-space）

演示「学生选择兴趣 → 系统自动组装桌面」全过程：

1. **兴趣选择**：基于应用使用画像推荐 4 项，学生自由增删（课表、宿舍生活、英语学习、图书馆、健身、校车、食堂、待办、快递、天气、音乐、习惯，共 12 项）
2. **系统组装**：读取多应用数据，按网格自动拼装
3. **桌面呈现**：生成专属学习空间桌面（超量自动分页，绝不溢出）

### 🧳 旅游·卡片空间（travel-main · 7步流程）

以「行程时间线」为主轴，按旅行阶段（行前 / 出发 / 大理 / 丽江 / 返程）用意图路由自动拼装多卡桌面，完整 7 步体验流程。

### 🧳 旅游·卡片空间（travel-fork · 6步直接生成）

导入后直接生成卡片空间，点击行程助手卡回到总流水微调，支持语音 / 对话告诉小艺调整行程，确认后重新生成。

### 💪 健身·卡片空间（fitness-card）

围绕健身场景的卡片桌面演示，展示运动数据、课程安排、成就进度等多卡组合（4×4 网格）。

## 技术说明

- 单文件 HTML + 内联 CSS/JS，零外部依赖
- 卡片尺寸遵循鸿蒙 NEXT：2×2 / 2×4 / 4×4
- 桌面严格落在 4 列 × 7 行网格内，多页自动分页
- 合规：卡片内无长按 / 二级菜单，编辑能力统一收口在元服务详情页
