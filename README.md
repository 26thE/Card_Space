## 各演示简介

### 📱 多场景卡片桌面（harmony-cards）

按「时空 + 信号意图路由」自动拼装不同场景的卡片桌面：

- 场景：居家晨间 / 通勤中 / 到店健身 / 晚间复盘 / 睡前
- 卡片（共 11 张）：今日训练（健身）、我的追更、基金收益、单词打卡（学习）、快递、用药提醒、天气、正在播放（音乐）、今日日程（日历）、阅读、睡眠/助眠
- 特性：鸿蒙 NEXT 规范（4 列 × 6 行网格、独立沙箱、整卡热区、编辑收口详情页）、实况窗胶囊、深色模式

### 🎓 学生·学习空间生成器（student-space）

演示「学生选择兴趣 → 系统自动组装桌面」全过程：

1. **兴趣选择**：基于应用使用画像推荐 4 项（课程表、宿舍生活、英语学习、图书馆），学生可自由增删；候选共 12 项，每项映射一个真实应用来源（教务系统、智慧校园、百词斩、智慧图书馆、运动健康、校园出行、智慧食堂、备忘录、菜鸟驿站、天气、音乐、习惯）
2. **系统组装**：读取多应用数据，按网格自动拼装
3. **桌面呈现**：生成专属学习空间桌面（超量自动分页，绝不溢出）

### 🧳 旅游·卡片空间（travel-main · 7步流程）

以「行程时间线」为主轴，按旅行阶段（行前 / 出发 / 大理 / 丽江 / 返程）用意图路由自动拼装多卡桌面。完整 7 步体验：

1. 小红书收藏夹：收藏攻略博文，分享到小艺触发行程生成
2. 小艺·对话列表：系统自动识别「大理+丽江 5.1-5.4」行程
3. 小艺对话·完善行程：一问一答确认住宿 / 美食 / 景点间交通
4. 总行程流水·确认：按天编排 Day1-Day4，可上下移动景点调整顺序
5. 生成卡片空间：按旅游阶段路由，点阶段标签切换卡片组合
6. 景点拍照攻略卡：到达景点（如玉龙雪山）时基于位置围栏自动弹出
7. 返程·复盘沉淀：行程回眸 + 花费小结，打分沉淀反哺识别权重

### 🧳 旅游·卡片空间（travel-fork · 6步直接生成）

travel-main 的精简变体：导入后直接生成卡片空间，无需逐步对话：

1. 小红书收藏夹 → 2. 小艺直接识别并生成 → 3. 生成卡片空间 → 4. 总行程流水微调（支持语音/对话告诉小艺，如「把玉龙雪山挪到下午」）→ 5. 景点拍照攻略卡 → 6. 返程复盘沉淀

### 🧭 单卡旅行助手 · 三阶段状态机（travel-singlecard）

把多卡桌面收敛为**单张 2×4 桌面卡片**，始终只显示用户的下一个行动：

- **三阶段状态机**：🧳 出行前 → 🗺️ 游览中 → 📸 回忆，按信号自动切换（演示中可手动切换查看）
- **双入口路径对比**：主动规划（小艺对话创建，带「小艺创建」徽章）/ 被动识别（信号触发，通知条一键创建卡片）
- **出行前**：出发天数 + 日期 + 天气胶囊 + ✓/✗ 准备清单（含清单进度）
- **游览中**：左侧景点美图 + 右侧下一站信息 + 打车 / 导航动作按钮；附近推荐支持按美食 / 住宿 / 景点 / 交通分类筛选
- **回忆**：照片 + 统计 + 分享，一键归档
- 卡片悬浮箭头拉起全程时间线；地点支持编辑 / 删除（编辑收口在详情页，符合规范）
- 附 `PRD.html` 产品需求文档与 `screenshots/` 设计迭代截图

### 💪 健身·卡片空间（fitness-card）

围绕健身场景的卡片桌面演示，已接入小艺助手面板：

- 卡片：今日训练（有氧 / 力量 / 恢复课程安排）、有氧打卡、饮食（蛋白 180g）等
- 支持小艺语音交互（打卡、查询训练安排）
- 桌面为 4×4 网格多卡组合

## 技术说明

- 单文件 HTML + 内联 CSS/JS，零外部依赖（travel-singlecard 另附 PRD 文档与截图）
- 卡片尺寸遵循鸿蒙 NEXT：2×2 / 2×4 / 4×4
- 桌面严格落在 4 列 × 6 行网格内（鸿蒙手机 4×6 宫格，Dock 栏不占宫格），多页自动分页
- 机框复刻华为 Mate 70 真机比例：机身 384×814（2.12:1 ≈ 160.9×75.9mm），屏幕 362×800（2.21:1 ≈ 2688×1216px）
- 桌面格子 76.75×77px ≈ 1:1 正方形，对齐真机卡片实测比例（真机 onAddForm 实测：2×2 卡片 513.5×513.5 严格正方，4×4 卡片 1178.8×1206.8 ≈ 1:1.02）
- 合规：卡片内无长按 / 二级菜单，编辑能力统一收口在元服务详情页
