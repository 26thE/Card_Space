# Card_Space

鸿蒙 NEXT 元服务卡片「自动组装桌面」演示集合 —— 两个纯静态单文件网页，无需构建，直接打开即可预览。

## 演示一：多场景卡片桌面（`harmony-cards/index.html`）

按「时空 + 信号意图路由」自动拼装不同场景的卡片桌面：

- 场景：居家晨间 / 通勤中 / 到店健身 / 晚间复盘 / 睡前
- 卡片：健身、追更、基金、学习、快递、用药、天气、音乐、日历、阅读、睡眠等 10+ 张
- 特性：鸿蒙 NEXT 规范（4×7 网格、独立沙箱、整卡热区、编辑收口详情页）、实况窗胶囊、深色模式

## 演示二：学生·学习空间生成器（`student-space/index.html`）

演示「学生选择兴趣 → 系统自动组装桌面」全过程：

1. **兴趣选择**：基于应用使用画像推荐 4 项，学生自由增删（课表、宿舍生活、英语学习、图书馆、健身、校车、食堂、待办、快递、天气、音乐、习惯，共 12 项）
2. **系统组装**：读取多应用数据，按网格自动拼装
3. **桌面呈现**：生成专属学习空间桌面（超量自动分页，绝不溢出）

## 技术说明

- 单文件 HTML + 内联 CSS/JS，零外部依赖
- 卡片尺寸遵循鸿蒙 NEXT：2×2 / 2×4（整行 2 行）/ 4×4
- 桌面严格落在 4 列 × 7 行网格内，多页自动分页
- 合规：卡片内无长按 / 二级菜单，编辑能力统一收口在元服务详情页

## 在线预览（GitCode Pages）

本仓库已配置为静态站点，根目录 `index.html` 为入口导航页，链接到两个演示：

1. 进入仓库 **设置 → 服务 / Pages**（或「静态页面」）
2. 选择部署分支 `main`，部署目录 `/`（仓库根目录）
3. 保存后访问 GitCode 提供的 Pages 地址，即可预览导航页与两个演示

> 如需本地预览，直接双击打开 `harmony-cards/index.html` 或 `student-space/index.html` 即可。
